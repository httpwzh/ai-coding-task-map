# AI 编程任务图

给独立开发者使用的本地 AI 编程任务地图。它把一次 AI 编程会话中的问题、分析、工具调用、文件修改和测试结果组织成可阅读的任务图。

## 当前状态

这是第一个基于假数据的只读原型，支持：

- 图形视图与线性视图切换
- 拖动、缩放和适应画布
- 用户问题、AI 分析、工具调用、文件修改、测试结果节点
- 分支关系和状态颜色
- 点击节点查看详情、关联文件和原始对话定位
- 节点折叠/展开

## 运行

需要 Node.js 18 或更高版本：

```bash
pnpm install
pnpm dev
```

然后打开终端输出的本地地址。

## 目录

- `docs/product-definition.md`：一页产品定义、MVP、技术方案和开发步骤
- `src/data/sampleSession.js`：原型假数据
- `src/App.jsx`：页面和交互
- `src/styles.css`：界面样式

## 当前边界

原型只读，不修改 DSH 核心逻辑，也没有云同步、登录、数据库或真实 AI 接口。

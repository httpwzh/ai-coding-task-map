# AI 编程任务图

给独立开发者使用的本地 AI 编程任务地图。DSH 弹窗默认汇总同一工作区的所有会话，按项目、会话、目标和最近清单快照展示进展记录；单会话事件图保留为钻取视图。

## 当前状态

这是本机项目任务图。独立打开 `http://127.0.0.1:4173` 时显示可编辑的示例项目；原固定会话样例可通过“会话样例”或 `?sample=1` 查看。从 DSH 会话输入栏的“任务图”按钮打开时，默认展示 DSH 工作区的会话目录（含归档成员及显式父子会话），先逐个读取最多 12 个会话的历史，再按需读取下一批。每个会话最多扫描 1600 条持久事件；超出上限或读取失败会标记为覆盖不完整。支持：

- 项目 → 会话 → 显式目标 / 最近一次任务清单，保留来源与记录时间；子会话按明确父会话归属
- 工作区切换、会话导航、分支折叠、图形与大纲视图、会话事件钻取
- 在项目图空白处拖动平移、使用缩放控件调整视野、拖动节点右上角手柄调整位置；位置可“重排”恢复自动布局
- 新建、修改状态和删除本地任务，在 DSH 来源节点上添加本地备注；本地任务统计与会话中的声明统计分开显示
- 历史读取状态、错误、未读批次与截断覆盖提示
- 单会话钻取显示问题、分析、工具调用、文件修改和测试结果；可逐页读取历史，最多展示 500 条
- 固定离线样例的项目管理总览；真实项目只显示结构化记录的声明状态，**不把事件或清单完成数当作项目交付百分比**

## 运行

最简单的方式是双击项目目录里的 **install-dsh-task-map.bat**，它会下载或更新项目、安装依赖、构建网页并启动本地服务。完成首次安装后，也可以双击 **启动 AI 编程任务图.bat** 只启动已有构建。关闭弹出的终端窗口即可停止服务。

也可以在终端运行：

```bash
pnpm install
pnpm dev
```

然后打开终端输出的本地地址。默认地址是 `http://127.0.0.1:4173`。若使用 Vite 开发模式，请显式指定 `--host 127.0.0.1 --port 4173`，插件只会向这一固定本机来源发送事件。

新电脑可直接双击 `install-dsh-task-map.bat`，自动下载项目、安装依赖、构建网页并启动本机服务。完整安装步骤见 [docs/new-computer-install.md](docs/new-computer-install.md)。DSH 插件管理器应安装仓库中的 `dsh-plugin` 子目录，不要把仓库根目录当成插件包。

## DSH 项目与会话

本机 DSH Web 和桌面 profile 都已注册 `dsh-plugin`。保持任务图预览服务运行：Web 模式使用先前已认证的标签页；桌面模式关闭并重新打开 DeepSeek Harness，使桌面 profile 重新加载插件，然后在会话输入栏点击“任务图”。桌面壳使用 `dsh-app://app` 的严格来源校验。当前 `http://127.0.0.1:19387` 属于桌面应用内部宿主，直接用外部浏览器访问裸地址会返回 `dsh web authentication required`。

项目范围优先来自 DSH 工作区的 `sessionIds`，归档会话仍作为成员；只有未登记的会话才按完全一致的工作目录推断分组，并在界面标明。无法确定归属时只显示当前会话，不假设属于某工作区。目标的“完成”及清单项的“完成”是会话中记录的声明，未经独立验收；最近清单仅是最后一次完整快照，不能代表项目的全部任务。点击会话节点可进入事件图；“加载更早事件”先展开缓存，再调用 DSH 的只读分页，每次最多增加 80 条，显示上限 500 条。关闭弹窗会释放只读会话引用。

插件和页面通过严格校验来源的 `postMessage` 通信，不绕过 DSH 的登录/跨域保护，也不把会话内容写进项目文件。编辑只写入 `127.0.0.1:4173` 来源下、按项目键隔离的浏览器 `localStorage`；不回写 DSH 会话、目标或清单。清除该浏览器站点数据会删除本地任务、备注及手动布局；不同浏览器或 profile 不共享。增量同步和分支折叠后，已手动移动的节点保留绝对位置，其余节点重新自动排布；如出现重叠，可点“重排”清除手动布局。独立打开任务图页面显示示例项目；读取失败时弹窗提供重试和固定会话样例回退。插件的配置注册位于本机 DSH Web profile 中，源码位于本仓库 `dsh-plugin`。

## 目录

- `docs/product-definition.md`：一页产品定义、MVP、技术方案和开发步骤
- `docs/dsh-data-mapping.md`：DSH 事件字段、插件入口和只读接入边界
- `src/data/dshSampleSession.js`：固定 DSH SessionEvent 结构样例
- `src/data/normalizeSession.js`：DSH 事件到任务图节点的转换层
- `src/data/projectModel.js`：跨会话目标、清单快照与来源关系归一化
- `src/data/taskGraph.js`：任务树与折叠布局（样例的项目统计独立于真实项目）
- `src/data/sampleSession.js`：把样例转换成画布数据
- `tests/*.test.js`：任务树、跨会话归一化、插件生命周期与分页回归测试
- `dsh-plugin/`：DSH Web 会话槽位的只读客户端插件
- `src/data/liveBridge.js`：iframe 来源验证与会话消息入口
- `src/App.jsx`：页面和交互
- `src/styles.css`、`src/management.css`、`src/responsive.css`、`src/history.css`：界面样式

## 当前边界

DSH 来源仍为只读，本地任务、备注和布局可编辑；不修改 DSH 核心或会话文件，也没有云同步、独立登录、数据库或 AI 请求。项目目录只覆盖 DSH 当前返回的工作区成员，历史按批次逐个读取，并受每会话 1600 条事件的上限约束；缺失历史的项目任务可能未显示。同一继承事件只有在父子会话均有完全相同的记录时才去重，跨会话目标声明不等于独立验收。单会话事件图最多展示 500 条持久事件；其阶段、优先级和依赖为推断，不是 DSH 的项目任务关系。暂不支持原始对话深链。
